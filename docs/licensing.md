# Licensing and attribution

The library's original scripts and documentation are MIT licensed. Every linked repository retains its own terms; metadata and README-derived facts do not relicense upstream code. API SPDX values are stored exactly; null and NOASSERTION require manual review. A permissive top-level license may not cover enterprise modules, bundled assets, models or dependencies.

Anthropic skills explicitly distinguishes Apache-licensed examples from source-available document skills. n8n, Dify and Activepieces are not automatically treated as uniformly permissive solely because their code is public. Consult their actual license files and module-specific terms before redistribution, commercial hosting or incorporation into a product. GitHub API classification alone is not a legal determination.

The first import records GitHub license metadata, with unknown/custom values retained. No exhaustive legal audit of all 24 projects was performed. Free LLM gateway code does not promise free inference: upstream providers control credentials, quotas and terms. README marketing claims are not independently verified guarantees.
