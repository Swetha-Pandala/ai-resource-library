# Find and reuse a resource

Browse category pages from README, search the CSV, or run `python scripts/search.py rag`. Search covers metadata and your notes. Catalog entries preserve upstream URLs and confirmed fork links separately.

A fork preserves Git history available to GitHub; it is not a complete backup of issues, releases, external assets, LFS content, hosted databases, services or future upstream changes. This library collects links and metadata; it does not install or run external projects.

Before using a project, open its current README, license and deployment instructions. Empty technologies, compatibility and installation fields mean not established, rather than no requirements. Use cases are suggested applications, not claims that a project was deployed or tested.

Edit `description`, `notes`, `tags`, `technologies`, `compatible_ai_tools`, `installation_requirements` and `use_cases` to record your research. Refreshes leave these fields intact. `upstream_description`, `upstream_topics`, license and language are refreshed separately.
