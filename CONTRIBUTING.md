# Contributing

Submit root repository URLs via the issue form or CLI. Preserve all earlier records and user notes. Deduplicate by stable ID, never by display name alone. Do not add discovered repositories without owner authorization. Do not copy entire upstream projects into category folders.

Run catalog validation and tests before submitting changes. Regenerate indexes/CSV after catalog edits. Add category definitions before assigning new category slugs. Mark uncertain metadata or classification for review; never invent license values or fork success.
